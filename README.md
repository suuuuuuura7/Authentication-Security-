### 🚀 Project Demo
This GIF demonstrates the secure OAuth authentication flow implemented in the application.

* **What you see:** The user navigates to the login page, chooses the GitHub authentication option, and is seamlessly redirected to the secure dashboard upon successful login.
* **Tech Stack:** Node.js, Express, Passport.js, and MongoDB.
* **Key Feature:** The integration of Passport's `passport-github2` strategy ensures secure, industry-standard authentication without the user needing to store passwords locally.
